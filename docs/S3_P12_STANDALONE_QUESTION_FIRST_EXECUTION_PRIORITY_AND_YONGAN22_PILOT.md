## Standalone FIRST release gates

A real standalone question must satisfy all requirements, separately:

1. **SOURCE_EXACT_SINGLE_QUESTION** — immutable source ID, original academic year/exam/page and binary SHA, complete original stem, all options in original order (or true/false), independently answerable without shared material/diagram, original answer-marker PDF coordinate or independently accepted equivalent, original scoring point allocation; source text is held privately.
2. **SCIENCE_SINGLE_UNIQUE_ANSWER** — independent model/science check, one correct option for single-choice, explanation and correction/HOLD if ambiguous, scientifically false, time-sensitive or misleading. A source question with an unresolved flaw stays HOLD even if structurally complete.
3. **KP_TARGET_REVIEW** — primary formal canonical KP matched against all available grade-semester authority with original semantic evidence, secondary KP optional. An old "G04-S1 nonmatch" can map G04-S2 without changing original source exam provenance. Keep distinct from question-science validation.
4. **OPERATOR_SOURCE_AND_PUBLIC_GATE** — explicit item/source final educational review, copyright/reuse or controlled learner redraw as relevant, test printable UI and explicit user approval after 114's entire original 25-paper screening gate. **No premature admission.**

A completed original-text extraction is **not** by itself a user-approved public exercise. The private working corpus may contain SOURCE_COMPLETE items long before their science/KP/public gates pass. This work needs direct question-level incremental throughput, not waiting for every original group diagram.
